# NEXDESIGN — Gaming Banner & Profile Creator

یک ابزار ساده برای ساخت طرح‌های گیمینگ با پیش‌نمایش زنده و دانلود خروجی PNG.

## فایل‌ها
- `index.html` — سایت اصلی؛ HTML، CSS و JavaScript داخل همین فایل هستند.
- `server.js` — سرور استاتیک ساده با Node.js برای اجرای سایت محلی.
- `README.md` — راهنمای اجرا.

## اجرای سریع بدون سرور
فایل `index.html` را با مرورگر باز کنید. بعضی مرورگرهای موبایل ممکن است دانلود فایل را محدود کنند؛ در این حالت روش سرور را امتحان کنید.

## اجرا با Node.js
نیازی به نصب پکیج اضافه نیست؛ فقط Node.js لازم است.

```bash
node server.js
```

سپس در مرورگر همان دستگاه به این آدرس بروید:

`http://localhost:3000`

برای تغییر پورت در لینوکس/macOS:
```bash
PORT=8080 node server.js
```

در PowerShell ویندوز:
```powershell
$env:PORT=8080
node server.js
```

## نکته‌های مهم
- این پروژه یک سایت استاتیک است و برای ساخت/دانلود تصویر به دیتابیس نیاز ندارد.
- `server.js` فقط فایل‌های سایت را سرو می‌کند؛ این سرور به‌تنهایی سایت را روی اینترنت منتشر نمی‌کند.
- برای انتشار آنلاین، پروژه را روی یک سرویس میزبانی استاتیک یا سرور Node.js قرار دهید.
- فونت Vazirmatn در صورت دسترسی به اینترنت از Google Fonts بارگیری می‌شود؛ اگر اینترنت در دسترس نباشد، فونت جایگزین نمایش داده می‌شود.
